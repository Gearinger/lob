OpenAI 同时做了三件事：涨价、杀定制、砍旧模型

如果你是 OpenAI 的开发者用户，过去两个月发生了三件事，合在一起看比单看任何一件都重要：

第一件：GPT-5.5 "Spud" 上线，API 价格翻倍。 4月23日发布，输入 token 从 $2.50/M 涨到 $5.00/M，输出从 $15/M 涨到 $30/M。性能确实有提升——Terminal-Bench 2.0 跑到 82.7%，100万 token 上下文窗口，幻觉率降了 52.5%。但涨价就是涨价，而且是直接翻倍。

第二件：Fine-tuning API 被废弃。 5月7日，OpenAI 通知开发者，自服务微调平台停止新增。已有的微调模型在基础模型下线前还能推理，但这条路到头了。想在 OpenAI 上做模型定制？没门了。

第三件：GPT-4.5 将于 6月27日退役。 距今 17 天。这是最后一个 GPT-4 时代的模型，它的下线意味着 OpenAI 的产品线彻底告别了 GPT-4 架构。o3 也在 8月26日退役。

三件事分开看，各有各的理由。放在一起看，指向同一个方向。

从平台到产品的战略转身

过去的 OpenAI，本质上是一个 AI 开发平台。你来我这里调 API，用我的模型做产品，我赚 token 费用。在这个模式里，开发者生态是核心资产——微调是黏性，低价是入口，旧模型是兼容性承诺。

现在的 OpenAI，越来越像一个高端 AI 产品公司。

涨价，是在筛选客户——不是所有开发者都值得服务，高价值场景才值得 GPU 算力。杀微调，是在统一产品体验——与其让一万个开发者各自折腾定制模型，不如提供一个"开箱即用"的最强模型。砍旧模型，是在减少维护负担——GPT-4 系列的工程债务太重了，是时候清算了。

这三件事加起来，翻译成人话就是：我不想做 API 平台了，我想做 AI 时代的 Apple。

开发者被推向何方

这个战略转身的代价，由开发者承担。

价格翻倍不是小事。对于大量 AI 应用来说，token 成本是核心成本项。GPT-5.5 的 $5/$30 定价，直接把很多"薄利"场景变成了"亏本"场景。OpenRouter 的数据显示，很多开发者已经在考虑切到 Gemini 3.5 Flash（$0.075/$0.30，便宜两个数量级）或者本地部署的开源模型。

微调被砍更致命。很多企业客户选择 OpenAI 的理由，不是 GPT 本身有多强，而是能在 GPT 基础上做行业适配。医疗、法律、金融——这些领域没有通用模型能直接用，微调是必经之路。OpenAI 砍掉这条路，等于在说：要么用我的通用模型将就，要么去找能做微调的平台。

而 GPT-4.5 的退役，对存量用户是直接打击。有些产品的 prompt 工程是围绕 GPT-4 时代的模型特性设计的，切换到 5.5 不是改个 model 参数那么简单——输出风格、token 消耗模式、甚至"废话程度"都不一样。

反直觉的信号

但如果你跳出开发者视角，会发现一个反直觉的事实：OpenAI 的这些动作，可能恰恰说明它在赢。

一家只有在市场地位足够强的时候，才敢同时涨价、砍功能、逼用户迁移。Google Cloud 不敢砍微调 API，Anthropic 不敢把价格翻倍——因为它们还在抢市场份额。只有当你确信客户离不开你的时候，才敢这么做。

而且从产品角度看，OpenAI 的选择不是没有道理。GPT-5.5 的"更少废话"设计，实际上是在优化推理效率——同样一个任务，输出更短的 token，总成本可能反而下降。微调的废弃，也可能是在为更强的内置能力让路——如果模型本身已经足够好，微调的边际收益就在递减。

产品人的冷静判断

作为产品人，面对这些变化，最重要的是不被情绪驱动。

短期：评估你的 AI 成本结构。 如果你的产品重度依赖 OpenAI API，6月27日前后需要做一个真实的成本测算。GPT-5.5 的价格翻倍，但输出更短——你的实际支出变化，取决于你的使用模式。

中期：考虑多模型架构。 单一依赖任何一家 AI 厂商，风险都在升高。Google Gemini 3.5 Flash 的 GA，给了一个极低成本的备选方案。不是所有场景都需要最强模型。

长期：关注 AI 产品的"定价权"转移。 OpenAI 敢涨价，本质上是在说：我的模型质量已经构成了足够的壁垒，用户愿意为溢价买单。这个信号对整个行业意味着——AI 产品的定价逻辑，正在从"成本加成"转向"价值定价"。如果你的产品能创造足够的价值，你的用户不会因为 AI 成本上升而离开。

GPT-4.5 的倒计时，不只是一个模型的退役。它是一个时代——AI 作为开放平台、低价竞争、开发者优先的时代——正在被另一个时代取代。在新秩序里，赢家是那些能用 AI 创造不可替代价值的人，而不是那些只会调 API 的人。
