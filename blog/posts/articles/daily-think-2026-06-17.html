产品思考 2026.06.17

互联网的主人正在换班：当 Bot 流量首次超过人类

Cloudflare 最新数据揭示了一个里程碑式的转折：57.4% 的互联网流量来自机器人和 AI 代理，人类只占 42.6%。AI Agent 的流量在一年内增长了 7,851%。互联网第一次不再是人类的专属领地。

这个数字本身并不意外——爬虫、搜索引擎、自动化脚本一直在消耗大量带宽。但这次不同的是增长引擎：新增流量的主体不是传统爬虫，而是 AI Agent。它们不是在抓取网页做索引，而是在替人类完成真实任务——浏览商品、填写表单、比价下单。

核心洞察

互联网正从「人类阅读界面」转变为「Agent 执行通道」。这不是渐进式变化，而是使用主体的根本性切换。为人类设计的产品，正在被机器重新消费。

01. 数据背后的真实变化

Cloudflare 的 57.4% 涵盖了所有自动化流量，但真正的新闻藏在细分数据里。传统爬虫的增长是线性的，而 AI Agent 流量的增长是指数级的。2025 年 6 月到 2026 年 6 月，Agent 流量翻了近 80 倍。

这些 Agent 在做什么？不是简单的 API 调用。它们在模拟人类浏览行为——打开网页、滚动、点击按钮、等待加载、填写表单。这说明一个关键转变：越来越多的 AI 交互不是通过 API，而是通过浏览器界面。API 是为程序设计的接口，浏览器是为人类设计的界面。当 Agent 开始大量使用浏览器，意味着它们正在「像人一样」访问互联网。

02. Chrome Auto-Browse：平台方的站队

Google 在这个趋势中下了一个大注。5 月宣布的 Chrome Auto-Browse 功能将于 6 月下旬在 Android 上线——这是 Chrome 内置的 Agent 浏览能力，可以自动执行多步骤任务：预约、询价、预订。

Google 还悄悄通过 Chrome 静默下载了一个 4GB 的 Gemini Nano 模型。这意味着浏览器本身正在变成 AI 的运行环境。当你打开 Chrome，你的设备里已经住着一个可以替你浏览互联网的 Agent。

这个策略的逻辑很清晰：如果 Agent 流量会超过人类流量，那么控制 Agent 运行环境的人，就控制了互联网的入口。Google 正在把浏览器从「人类的窗口」升级为「Agent 的操作系统」。

03. 对产品设计的三重冲击

当互联网的主要用户不再是人，产品设计的底层假设需要被重写。

  • UX 不再只是给人看的——产品页面需要同时为人类审美和 Agent 解析优化。结构化数据、语义化 HTML、标准化的表单流程，这些「技术性」的东西会变得和视觉设计一样重要
  • 反机器人机制面临身份危机——CAPTCHA 和反爬虫系统过去是为了区分人和机器。但如果 Agent 代表人类行事，阻拦 Agent 就等于阻拦用户自己。产品需要新的「身份验证」逻辑：不是区分人和机器，而是区分「被授权的 Agent」和「未授权的 Agent」
  • 转化率的定义需要扩展——传统转化率衡量的是「人类用户是否完成目标行为」。当 Agent 替用户下单，转化率的计算需要考虑：Agent 是否真的代表了用户的意图？还是只是完成了技术上的点击？

04. 更大的图景

57.4% 这个数字只是开始。Chrome Auto-Browse 上线后，Agent 流量会再上一个台阶。当每个手机用户的浏览器里都住着一个 AI Agent，当每个企业都在用 Agent 自动化业务流程，互联网流量的「人机比」会继续向机器倾斜。

这引出一个更根本的问题：互联网是为谁建的？ 最初它是学术网络，后来它变成人类的信息高速公路。现在它正在变成 Agent 的执行通道。基础设施没有变——TCP/IP、HTTP、HTML 都在——但使用者变了。

对于产品团队来说，最务实的行动是：检查你的产品是否能被 Agent 有效访问。那些依赖复杂 JavaScript 渲染、反爬虫验证码、动态表单的产品，可能会在 Agent 时代失去一大块用户——因为「用户」的定义正在扩展，而你的产品可能还没有为新用户做好准备。
