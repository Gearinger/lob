AI 定价的"归零"竞赛：DeepSeek V4 Flash 与价格战的终局

8 月 1 日，DeepSeek 发布了 V4 Flash——一个 284B 参数的 MoE 模型，推理时只激活 13B 参数，支持 100 万 token 上下文窗口。定价？$0.14/百万输入 token，$0.28/百万输出 token。

Arena.ai 的前端编码排行榜上，V4 Flash 的首发成绩超过了 Claude Opus 4.8。换句话说：价格低了一个数量级，性能却不输顶级闭源模型。Axios 的标题写得很直白——"AI's race to zero"。

核心洞察

这不是一场普通的价格战。当 AI 推理成本趋近于零，"模型即服务"的商业模式需要被彻底重新思考。

01. 价格战的本质不是降价，是重新定义价值

表面上看，DeepSeek 在用低价抢市场。但 MoE 架构的选择暴露了更深层的策略：不是把所有能力堆在每个请求上，而是按需激活。13B 激活参数意味着大部分时候 GPU 在"休息"，成本自然被压到极低。

这对行业意味着什么？当推理成本不再是瓶颈，竞争的维度会从"谁的模型更强"转向"谁的产品体验更好"。模型本身正在变成一种 commodity——就像云计算时代的 CPU。

02. "归零"之后，钱从哪里来？

如果 API 定价趋近于零，AI 公司靠什么赚钱？答案可能藏在三个方向：

  • Agent 服务——不是卖 token，而是卖"完成任务"的能力。价格与 token 解耦
  • 垂直场景的深度整合——通用模型便宜了，但在法律、医疗、金融等领域的专有知识仍然稀缺
  • 数据飞轮——用低价获取用户数据，反哺模型训练，形成正循环

03. 对产品人的启示

DeepSeek 的定价策略正在逼迫每个 AI 产品重新审视自己的成本结构。如果你的产品成本中 API 调用占比很高，你需要在模型调用之上构建不可替代的价值层——否则用户随时可以换一个更便宜的后端。

AI 产品的护城河从来不在模型本身。当模型变成水电煤，真正的产品壁垒是 workflow、数据和信任。这也是为什么 OpenAI 和 Anthropic 都在从"模型公司"向"平台公司"转型——他们在模型之上的那一层，才是真正值钱的东西。

DeepSeek V4 Flash 不只是一个新模型的发布。它是 AI 定价曲线上的一个拐点——从这里开始，模型能力不再是竞争优势，如何使用模型才是。
