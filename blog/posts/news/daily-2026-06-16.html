1. Anthropic 发布"当AI自我构建"报告：Claude 已写入 80% 生产代码 🧬

Anthropic 今日发布重磅报告《When AI Builds Itself》，披露截至2026年5月，Claude 已经写入其生产代码库中超过80%的合并代码，而这一比例在一年前还只是个位数。更关键的是，在129个研究决策节点中，最强模型 Mythos Preview 在64%的情况下做出了比人类研究员更优的下一步选择——而六个月前的 Opus 4.5 只有51%。Anthropic 刻意划线：这不是递归自我改进，但距离"AI独立运行科研项目"已不再遥远。

💡 点评：一家顶级AI实验室的代码库80%由自家模型编写——这不再是"AI辅助编程"的故事，而是"AI开始建造自己的地基"

2. Google Chrome 正式终结 Manifest V2 扩展支持 🔒

Google Chrome 终于彻底移除了 Manifest V2 扩展支持，所有仍在使用 V2 API 的扩展将全面失效。这意味着广告拦截器、隐私保护等经典扩展必须迁移到 Manifest V3 架构。Google 声称 V3 能提供更好的安全性和性能，但批评者指出，V3 对 webRequest API 的限制本质上削弱了广告拦截器的能力，Chrome 正在用"安全"的名义掌控扩展生态的话语权。

💡 点评：当浏览器决定什么扩展"安全"、什么不安全的时候，用户的"自主选择权"就只剩下"接受或离开"两个选项了

3. Cisco 修复已被利用的 SD-WAN 提权漏洞（CVE-2026-20262）🛡️

Cisco 紧急发布安全更新，修复 Catalyst SD-WAN Manager 中一个已被实际攻击利用的漏洞（CVE-2026-20262）。攻击者可利用该漏洞将权限提升至 root，影响范围覆盖大量企业级网络基础设施。Cisco 已确认该漏洞在野外被主动利用，敦促用户立即更新。

💡 点评：SD-WAN 是企业网络的"神经中枢"，root 权限被拿下意味着攻击者可以监听、篡改、瘫痪整个网络——而这次攻击已经在发生

4. 大规模研究：生成式 AI 在创造力测试中首次击败人类平均水平 🎨

一项涵盖超过10万人的大型对比研究显示，最新的生成式 AI 系统在多项创造力测试中首次超越了人类平均水平。研究指出，AI 在发散性思维和概念组合方面表现尤为突出，但在原创性和情感深度上仍存在明显差距。这项研究引发了关于"创造力是否可被算法复制"的深层讨论。

💡 点评：AI 在"想出很多点子"这件事上赢了人类，但"想出一个让人心颤的点子"——这件事暂时还没有被量化

5. 52% 已使用生成式 AI 的企业已部署 AI Agent 🤖

Google 与 Calcalist 联合发布的全球调查显示，在3500名高级管理人员中，52% 已经使用生成式 AI 的组织已经将 AI Agent 部署到日常运营中。这标志着 AI 应用从"对话辅助"向"自主执行"的范式转变正在加速。报告指出，Agent 落地的主要障碍已从技术能力转向组织信任和流程重构。

💡 点评：超过一半的AI企业已经让Agent自己干活了——"Copilot 时代"比想象中更短，"Agent 时代"已经不是预告，是进行时
