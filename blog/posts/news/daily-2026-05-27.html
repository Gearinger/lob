1. Meta 向开源项目 Heretic 发出法律通知，开源 AI 边界再起争议

开源项目 Heretic 收到 Meta 代表律师的停止通知，被迫从仓库移除 Llama 衍生模型权重。项目转向德国 Codeberg 托管，并宣布正研发「技术手段」绕过单一托管商依赖。社区反应激烈——评论区大量指向 Meta 曾被指控使用 BT 下载的书籍训练 Llama 这一事实。

一句话点评：开源许可证的「免费午餐」从来都是有条件的，只是这次条件来得比预期早。

2. DeepSeek 推进 102.9 亿美元融资，创始人重申开源路线不动摇

据 Bloomberg 报道，DeepSeek 正推进超 100 亿美元融资轮，创始人梁文锋明确表示将继续走 AGI 路线、坚持开源模型而非短期商业化。社区评论指出：模型架构优势半衰期约一年，开源是保持迭代速度的手段而非慈善。

一句话点评：当一个实验室告诉你「我不急着赚钱」，要么是理想主义，要么是算清了更大的账。

3. Anthropic 推出 13 门免费 AI 课程，含 MCP、Claude Code 等实践内容

Anthropic 正式上线官方培训目录，通过 Skilljar 平台提供 13 门以上免费课程，覆盖 Claude API、MCP 协议（含 STDIO/StreamableHTTP 进阶）、Claude Code 使用、Agentic AI 部署等，完成可获证书。已完成的用户特别推荐 MCP 进阶课程。

一句话点评：大厂自己做教育，是人才培养还是用户心智占领？两者兼得，何乐不为。

4. Gemini 3.5 Flash 被指基础算术出错——产品「降速」与基准测试的落差

用户在 Gemini App 发现 300+140=460 被直接接受，而切到 Extended Thinking 或 AI Studio 即可得到正确答案。社区讨论指向默认「Standard」模式实际不进行推理——产品配置让基准分数与用户体验产生了严重落差。

一句话点评：模型的真实能力藏在设置深处，你的「默认」不等于模型的「能力」。

5. vLLM 合并 Rust 前端，高并发预处理性能提升 5 倍；OpenRouter 完成 1.13 亿美元 B 轮

vLLM 合并 Rust 替代 Python API Server，单进程预处理负载从约 162 req/s 提升至 837 req/s。与此同时，多模型路由平台 OpenRouter 宣布 B 轮 1.13 亿美元，六个月内 Token 处理量从 5T 增至 25T/周。

一句话点评：基础设施层正在经历「用脚投票」的优胜劣汰——性能和规模才是硬通货。
