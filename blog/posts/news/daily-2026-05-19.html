1. NVIDIA 首款 AI Agent CPU「Vera」正式交付：英伟达从 GPU 供应商转型全栈计算方案 ⚡🤖

NVIDIA 于5月18日开始向 Anthropic、OpenAI、SpaceX AI 和 Oracle Cloud Infrastructure 交付其首款专为 Agentic AI 设计的 Vera CPU 系统，由 NVIDIA 高管 Ian Buck 亲自送达。Vera 是 NVIDIA 从 GPU 供应商向全栈 AI 计算方案提供商转型的里程碑产品，标志着 AI 计算从"GPU 加速"进入"专用 CPU 驱动 Agent"的新阶段。内存带宽较上一代提升30%，专为多 Agent 协作场景优化。

💡 点评：当芯片公司开始造 CPU 而不是 GPU，意味着 AI 的计算形态正在从「加速单个模型」转向「驱动一群智能体」

2. 马斯克诉 OpenAI 案终局：陪审团不到2小时一致驳回，1340亿美元索赔全部落空 ⚖️💰

5月18日，加州联邦法院9人陪审团仅用不到2小时便一致裁决，以诉讼时效届满为由驳回马斯克针对 OpenAI 及奥特曼的全部诉讼请求。马斯克索赔1340-1500亿美元的诉求全部落空，OpenAI 重大法律障碍清除，市场普遍认为将有利于其推进 IPO 计划，目前 OpenAI 估值超过8500亿美元。奥特曼、格雷格·布罗克曼及微软 CEO 纳德拉均出庭作证。

💡 点评：诉讼时效成了 OpenAI 的护身符，但这不意味着争议消失——它只是换了一种形式继续

3. Microsoft Copilot Studio 企业部署规模曝光：16万+组织运行40万+自定义 Agent 🏢🔧

截至2026年5月19日，超过16万个组织在 Microsoft Copilot Studio 上部署了40多万个自定义 Agent，成为企业级 Agentic AI 平台中体量最大的参与者。企业正在从"试点 AI"进入"大规模 Agent 部署"阶段，Agent 消费模式也从 API 调用转向信用池配额制。金融、医疗、制造业成为三大应用场景。

💡 点评：40万个 Agent 在企业中运转——问题不再是「能不能用」，而是「谁来负责」
