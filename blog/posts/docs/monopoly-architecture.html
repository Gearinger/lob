3. 组件结构

整体采用 MVC 模式，所有代码内联于单个 HTML 文件。

模块职责关键函数
🎲 DiceEngine骰子投掷、双骰判定、随机数生成roll(), checkDouble()
🗺️ BoardRendererCanvas 绘制环形棋盘、玩家令牌、格子高亮、动画drawBoard(), animateMove(), drawDice()
📊 UIPanel玩家资产面板、回合指示、按钮操作区updatePanel(), showModal(), hideModal()
🤖 BotAIBot 决策执行、思考动画、策略参数decide(), executeAction(), showThinking()
🃏 CardDeck机会/命运卡牌堆、抽卡、效果执行draw(), shuffle(), execute(card)
💰 EconomyEngine买地、租金结算、建造升级、破产判定、资产统计buyLand(), payRent(), upgrade(), bankrupt()
🔄 GameLoop游戏主循环、回合切换、回合数计时、胜利判定startTurn(), endTurn(), checkWin(), endGame()
💾 SaveManagerlocalStorage 存档/读档（可选功能）save(), load(), hasSave()

4. 游戏主流程

游戏启动 → setup() [初始化棋盘、玩家、金币、卡牌]
    ↓
startTurn(player) [玩家回合开始]
    ↓
roll() → 显示骰子动画 → 获得点数
    ↓
检查 isDouble → true: 可继续掷 | false: 结束回合
    ↓
移动令牌 → animateMove() → 到达目标格
    ↓
触发格子的效果（switch cell.type）:
  land:     有主? → payRent() : buyPrompt()
  chance:   CardDeck.draw('chance') → 执行效果
  fate:     CardDeck.draw('fate') → 执行效果
  station:  payStationRent()
  airport:  teleportPrompt() [玩家选择目标]
  jail:     检查 inJail ? → 保释/掷双骰 : 正常路过
  start:    awardStartMoney()
  park:     无事发生
    ↓
endTurn() [切换到下一玩家]
    ↓
检查胜利条件 → 所有对手破产? 或 回合=20? → endGame()
    ↓
若无胜利 → startTurn(下一玩家)

5. Bot 决策状态机

Bot 回合开始
    ↓
状态: IDLE
    ├─ 等待 0.5-1.5 秒（思考动画）
    ↓
状态: DECIDING
    │
    ├─ 阶段A：是否买地?
    │   计算: 资金 > 地价 × 买地意愿阈值?
    │   鹰: 0.6 | 龟: 1.2 | 狐: 0.9
    │   → 买 → BIDDING
    │   → 不买 → 阶段B
    │
    ├─ 阶段B：是否升级?
    │   计算: 资金 > 盖房费 × 升级意愿阈值?
    │   鹰: 0.8 | 龟: 1.5 | 狐: 1.0
    │   → 升级 → UPGRADING
    │   → 不升级 → 阶段C
    │
    └─ 阶段C：是否交易?
        狐Bot 专属（交易接受度高）
        评估当前提案，接受/还价/拒绝
    
状态: EXECUTING
    ├─ 执行决策（买地/升级/交易）
    ├─ 显示 Bot 思考日志（"狐狸Bot 购买了上海地块"）
    └─ 更新 UI
    
状态: WAITING
    └─ Bot 回合结束，切换下一玩家

注意: Easy 模式下，阶段A/B 各有 30-40% 概率故意做出次优决策

6. Canvas 环形棋盘布局

布局: 环形（矩形路径），4 边各 10 格
     ┌──────────────────┐
     │ 10   11  12  ...  18   19│ ← 北边（顶部）
     │  9                    20│ ← 西边 / 东边
     │  8                    21│
     │  7                    22│
     │  6                    23│
     │  5                    24│
     │  4                    25│
     │  3                    26│
     │  2                    27│
     └──────────────────┘
     ← 南边（底部）1 = 起点

格子宽度: 60px，字体12px
令牌大小: 20px 圆形，4个玩家不同颜色
环形角度: 每格 9°（360/40）
起点（1号）: 左下角，顺时针编号

Canvas 尺寸建议: 900×700px（适合 1080p 屏幕）。棋盘居中，左右两侧预留 200px 给 UI 面板。

7. 动画时序

事件动画时长说明
骰子滚动800ms随机抖动动画，最终显示点数
令牌移动300ms/格平滑直线移动，逐格动画
卡片滑入400ms从顶部滑入，显示 3 秒后消失
Bot 思考500-1500ms显示"🤔" + 随机思考文案
租金弹窗600ms金币从付款方飞向收款方动画
地皮建造400ms格子上建筑图标放大弹出效果

10. 实现优先级（Phase 1 MVP）

P0 — 核心循环
骰子 → 移动 → 落地判定 → 买地/付租 → 结束回合。2个Bot（鹰+龟），4格环形地图测试版。
P1 — 完整棋盘
40格完整城市地图，Canvas 渲染环形棋盘，3个Bot（鹰+龟+狐），全部卡牌。
P2 — UI 打磨
玩家面板、弹窗系统、所有动画（骰子/移动/卡片/租金）、Bot 思考日志。
P3 — 特殊格
机场传送、监狱禁足、起点奖励、竞拍机制、交易系统。
Recommended Next Step：从 P0 开始，先做 4 格测试版验证核心循环正确，再逐步扩展到完整 40 格。
