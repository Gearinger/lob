大富翁 Online

版本 v0.1 · 状态：草稿 · 作者：Lob

一款基于中国城市地图的经典大富翁玩法网页游戏，支持玩家 vs AI Bot 单人模式，未来可扩展多人联机。

1. Executive Summary

经典大富翁玩法在中国有极强的情感基础（强手棋、大富翁游戏盘），但近年来缺乏有吸引力的线上版本。现有网页端产品普遍界面老旧、交互粗糙、AI Bot 无趣。

本产品定位为：一款精致、有策略深度、视觉风格现代化的中国城市大富翁网页游戏。以「玩家 vs AI Bot」为核心首发模式，重现经典地皮买卖、建造升级、命运卡、博弈对抗的核心乐趣。

差异化点：中国城市地图（省会+直辖市）+ 中国特色命运卡（政策/机遇/风险）+ 聪明有进攻性的 AI Bot + 现代暗色 UI。

2. Problem Statement

谁有这个问题？

20-40岁对中国经典大富翁有情怀记忆的用户，想要随时随地来一局，不需要下载 App，不需要队友。

现有方案的痛苦点：

  • 传统桌游：需要凑人、时间、道具，门槛高
  • Steam/App 大富翁游戏：需要下载安装，很多收费且品质参差
  • 网页版：界面老旧、交互反人类、AI Bot 弱智（永远买不到地/永远乱买）

证据：豆瓣/B站上经典大富翁相关内容持续有热度，但找不到一个能打的在线版本。

3. Target Users & Personas

核心用户

怀旧玩家
25-40岁，童年玩过强手棋/大富翁，现在想重温，但没有时间和人凑桌游。想要一个 AI Bot 能陪打的网页版，随时打开随时玩，30-60分钟一局。
策略游戏爱好者
18-35岁，喜欢回合制策略游戏（文明、英雄无敌），追求博弈深度。经典大富翁的"买地-盖房-收租"博弈链能否带来足够策略深度是他们的核心关注点。
休闲社交用户
18-30岁，和朋友远程玩游戏的场景。首发 AI 模式是替代方案，真正的目标是多人联机模式（Phase 2）。

4. Strategic Context

为什么现在？

  • HTML5 游戏技术成熟，单文件可承载复杂游戏逻辑
  • 大富翁核心玩法简单，但 AI Bot 设计有壁垒——好玩的 Bot 需要精心调参
  • Lob 站已有游戏矩阵（扑克/斗蛐蛐/德州扑克），大富翁是策略类补充
  • 中国城市 IP 有共鸣感，差异化强于"经典欧美地图"

Phase 规划

  • Phase 1（MVP）：玩家 vs 3个 AI Bot，单机运行，中国省会城市地图，完整大富翁核心玩法
  • Phase 2（联机）：WebSocket 中转，支持 2-4 人真实联机对战
  • Phase 3（社交）：好友系统、排行榜、录像回放

5. Solution Overview

地图设计

采用环形棋盘路线，共 40 格（与经典大富翁一致）。

  • 地皮格：25 格 — 中国省会/直辖市，每块地有价格、等级（空地→茅屋→房屋→楼房→摩天楼）、地价租金表、颜色分组（集齐同色全部地块租金+10%）
  • 机会格：5 格 — 抽取机会卡（获得收益/失去资产/特殊事件）
  • 命运格：5 格 — 中国特色命运（政策影响/市场波动/机会事件）
  • 起点格：1 格（1号） — 经过起点时获得固定奖励（跨过0位时触发，开局在1号不算经过）
  • 公共设施格：2 格 — 火车站×1（7号北京）、机场×1（32号成都）。31号为监狱格（非火车站）。火车站拥有后被路过收取¥200×骰子总点数；机场拥有后可传送任意城市（每局限1次）
  • 监狱/过路格：1 格（31号） — 路过正常支付过路费；连续掷三次双骰则被抓进监狱，禁足3回合
  • 免费停车格：1 格 — 无事发生

核心游戏循环

  1. 玩家回合开始 → 掷骰子 → 移动
  2. 落地判定：空地/已有地/机会/命运/特殊格
  3. 玩家决策：买地/竞拍/跳过
  4. AI Bot 行动（各自回合）
  5. 回合结束 → 下一玩家

胜利条件

所有玩家连续破产，或经过约定回合数（默认 20 回合）后，资产最高者胜出。

6. AI Bot 设计（核心壁垒）

AI Bot 是本产品的核心竞争力。好玩的大富翁需要 Bot 有"性格"和"策略"。

Bot 类型

🦅 鹰派Bot
激进买地、高频升级、优先攻击富裕玩家。有钱就盖房，抢占核心地块不惜负债。
🐢 龟派Bot
保守稳健、低买高卖、避免冲突。专注于积累免费地块，尽量少交易。
🦊 狐狸Bot
机会主义、擅长讨价还价。买地看对手而不是看价格，博弈谈判能力强。

Bot 决策模型

  • 每次落地：计算期望收益 vs 当前资金，决定买/竞拍/放弃
  • 每个回合结束：评估升级优先级（按地价/对手路过频率加权）
  • 对手接近时：优先升级对方必经之路的地块
  • 交易请求：根据自身资产/地块组合评估是否接受

注意：Bot 难度应可调。Easy Bot 有 30% 概率做出次优决策；Hard Bot 始终做最优决策（模拟蒙特卡洛搜索）。

6.2 Bot 行为决策树（详细规则）

每个 Bot 有完整的 IF→THEN 决策树，分为 Easy（随机扰动）和 Hard（最优决策）两个模式。

🦅 鹰派 Bot — 激进进攻型

Easy 模式（30% 次优概率）

买地决策
IF 资金 > 地价 × 0.6 THEN 购买  (30%概率: 放弃购买)
IF 对手已有同色地块 AND 地价 < ¥8,000 THEN 立即购买（不惜抬价）
IF 资金 < 地价 AND 资金 > 地价 × 0.8 THEN 竞拍（出价 = 地价 × 0.8~1.0）
升级决策
IF 资金 > 盖房费 × 0.8 THEN 升级（30%概率: 跳过升级）
IF 有对手必经之路的空地 THEN 优先升级该地
IF 自身已有地皮位置 > 5格未升级 THEN 升级该地
交易决策
不接受任何主动交易（认为交易会削弱进攻优势）。对方提出交易 → 直接拒绝。
负债容忍
允许负债至 ¥-8,000。超过则停止买地，只升级已有地块。

Hard 模式（最优决策）

买地决策
IF 资金 > 地价 × 0.6 THEN 购买
IF 计算期望收益(EV) = (租金收入/回合) × 剩余回合数 > 地价 THEN 购买
IF 买地后资金 < ¥2,000 THEN 跳过（保留应急资金）
IF 对手现金 > ¥10,000 AND 地价为S/A级 THEN 购买（瞄准对手经过概率）
升级决策
IF 资金 > 盖房费 × 0.8 AND 买地后资金 > ¥3,000 THEN 升级
IF 该地位置在任意对手5格以内 THEN 立即升级（战略封锁）
IF 自身资金 > ¥15,000 THEN 激进升级（不在乎负债）

🐢 龟派 Bot — 保守稳健型

Easy 模式（30% 次优概率）

买地决策
IF 资金 > 地价 × 1.2 THEN 购买（更保守的买地门槛）(30%概率: 提高到1.5倍)
IF 地价为F级 AND 资金 > 地价 × 0.8 THEN 购买（只买便宜地）
IF 其他玩家正在争抢某地块 THEN 放弃（让给他们）
升级决策
IF 资金 > 盖房费 × 1.5 THEN 升级（30%概率: 跳过）
IF 有2块以上同色地块 THEN 升级该颜色（激活颜色加成）
IF 资金 < ¥5,000 THEN 停止升级（保留现金）
交易决策
等价交换可谈（±20%以内接受）。非等价交易 → 拒绝。
负债容忍
不允许负债。资金 < 地价 × 1.2 时停止买地。

Hard 模式（最优决策）

买地决策
IF 资金 > 地价 × 1.0 THEN 购买（购买前预留¥3,000应急）
IF 地价为F级 THEN 购买（低成本积累地块）
IF 某颜色地皮已集齐2块以上 THEN 优先购买该颜色剩余地皮（追求颜色加成）
升级决策
IF 资金 > 盖房费 × 1.2 THEN 升级
IF 集齐同色全套 THEN 立即升级（颜色加成激活后收益翻倍）
IF 剩余游戏回合 < 10 AND 自身地块 > 5 THEN 激进升级（收割期）

🦊 狐狸 Bot — 机会主义型

Easy 模式（40% 次优概率）

买地决策
IF 资金 > 地价 × 0.9 THEN 购买（40%概率: 放弃便宜地块）
IF 对手资金 < ¥5,000 THEN 购买任何地（趁对手虚弱）
IF 对手刚被租金收割过（损失>¥1,000） THEN 购买其附近地块（落井下石）
IF 某地块被多个对手争夺 THEN 等待竞拍后期入场（渔翁得利）
交易决策（核心能力）
收到交易提案:
  IF 自身净赚 > ¥500 THEN 接受
  IF 自身净赚 ±¥500 以内 THEN 还价（要求加价10~20%）
  IF 交易包含对手核心地块 THEN 拒绝（不让对手凑齐颜色）
  IF 自身资金 < ¥3,000 THEN 拒绝（现金流紧张）
(40%概率: 即使划算也拒绝，增加不可预测性)
负债容忍
允许负债至 ¥-3,000。负债时优先通过交易套现而非卖地。

Hard 模式（最优决策）

买地决策
IF 资金 > 地价 × 0.9 THEN 购买
IF 计算对手购买意愿（基于资金和已有地块）> 0.7 THEN 等待竞拍后期入场
IF 对手资金 > ¥12,000 AND 地价 < ¥10,000 THEN 购买（针对富裕对手）
IF 游戏进入后半段（>10回合）AND 自身资产排名 >= 2 THEN 保守操作
交易决策
IF 交易EV > 0 THEN 接受
IF 交易EV ∈ [-500, 0] THEN 还价（加价15%）
IF 交易让自身集齐颜色全套 THEN 接受（甚至主动让价）
IF 交易让对手集齐颜色全套 THEN 拒绝

Bot 决策优先级总览

决策类型 🦅 鹰 🐢 龟 🦊 狐
买地优先级对手必经地 > S/A级 > 任意F级 > 凑颜色 > 低价S/A对手虚弱时 > S/A > 任意
升级优先级封锁对手 > 已有地 > 任意凑颜色 > 已有地 > 任意收割期激进 > 任意
交易态度拒绝一切等价交换可谈主动讨价还价

5.2 机会/命运卡效果精确定义

通用规则

  • 所有卡片效果立即执行（除非另有说明）
  • 金币变化显示弹窗动画（金币飞入/飞出动效）
  • 若无有效目标（如降级但已是最底层），卡片效果跳过

机会卡（C-01 ~ C-16）精确效果

#卡片精确效果
C-03出售房产选择最贵地块出售，获得该地块盖房费×80%。若无任何地块，无效。
C-08免费盖房选择任意已有地块盖1栋（最高到摩天楼level=4）。若无地块，无效不触发。
C-11慈善捐款支付¥300，获得"慷慨"标记。本局下次收取租金时，租金收入+10%（四舍五入）。标记仅生效1次后清除。
C-14加速发展本回合立即获得额外掷骰机会。双骰也适用（可连续触发）。

其余机会卡（C-01/02/04/05/06/07/09/10/12/13/15/16）为直接金币增减，无特殊规则。

命运卡（F-01 ~ F-16）精确效果

#卡片精确效果
F-01经济过热所有玩家所有地块租金×0.5（持续1回合）。回合结束后恢复。影响自身。
F-02政策利好指定一种颜色（如红/蓝/绿），该颜色所有地块租金+50%（持续2回合）。若已有颜色加成，先叠加再计算。
F-03房产泡沫所有玩家的摩天楼(level=4)降为房屋(level=2)。原本不是摩天楼的跳过。
F-07汇率波动所有玩家随机获得/损失¥500~¥1,500（由系统随机决定每个人）。正负各50%概率。
F-10台风灾害随机选择该玩家1块有建筑的地块（level>0），降1级。若无任何建筑，该卡无效跳过。
F-11IPO上市所有玩家按当前总资产（含地皮+建筑+现金）× 5%缴税。不足¥500按¥500收取。
F-12市场调研本回合可见所有Bot手头现金（显示在玩家面板上），下回合恢复正常。不影响Bot决策。
F-13租金管制本回合所有租金收入减半（自己付别人的租金也减半）。双面效果。

5.3 经济平衡验证

初始资源

项目数值
初始金币/玩家¥15,000
总玩家数4人（1玩家+3Bot）
游戏开始金币总量¥60,000
总地价（28块）约 ¥170,000（全部售出后）
金币注入速度（每圈起点）¥8,000/圈（4人×¥2,000）

经济健康指标

通缩风险评估
每圈注入¥8,000，每次租金流出约¥300~¥1,500（取决于地皮等级）。结论：通缩风险低。每圈注入量覆盖约5~26次基础租金，足够支撑游戏进行。
破产速度评估
持有S级地+摩天楼（¥15,000租金）：对手每次路过损失¥15,000。持有¥15,000现金可承受1次。Bot会在3~5回合内积累足够资金触发破产。结论：破产速度合理，20回合足够决出胜负。
Bot会不会过于强势？
玩家有¥15,000初始资金，可购买2块A级地（S/A/B）后资金剩余¥3,000~¥5,000，仍够支付1~2次租金。新手保护规则：前10回合若Bot连续买走3块S/A级地，剩余S/A价格临时-20%。结论：玩家有喘息空间，不会被碾压。
游戏时长验证
4玩家×20回合×平均2~4分钟/回合（玩家操作慢，Bot快）= 约32~64分钟，取中位约45分钟。符合"30-60分钟"目标。

Phase 1 核心指标

  • 单局平均时长：30-60 分钟（玩家愿意花一局时间的证明）
  • AI Bot 胜率：玩家胜率 40-60%（Bot 既要有挑战性又不能太碾压）
  • 功能留存：进入游戏 → 完成一局的用户比例 ≥ 70%

未来指标

  • 人均游戏局数（复玩率）
  • 分享率（分享游戏截图到社交媒体）
  • 多人模式转化率（从 AI 模式引导到联机模式）

8. User Stories & Requirements

Epic：大富翁 MVP

作为一个怀旧玩家，我想要打开网页就能和 AI Bot 来一局大富翁，以便在碎片时间内重温经典游戏的乐趣。

US-01 地图渲染
地图完整渲染 40 格，含中国城市名称，环形排列，支持点击查看地块详情。地块颜色区分不同城市等级。
US-02 骰子与移动
点击骰子触发动画，两颗骰子点数显示，移动令牌平滑动画移动至目标格。可掷双骰（连续行动）或进监狱（掷出双骰三次触发）。
US-03 地皮买卖
落地空地时弹出购买确认框（价格/预期租金/已拥有者）。拥有地块后支持建造升级（茅屋→房屋→楼房→摩天楼），每次升级费用×1.5，租金×2。
US-04 租金结算
玩家落地对手地块时自动触发租金结算弹窗，动画显示金币从付款方转移至收款方。若余额不足则触发破产流程。
US-05 机会/命运卡
落地机会/命运格时，卡片从顶部滑入动画，内容随机。卡片类型：获得金币/失去金币/失去收益/免费盖房/移除建筑/交换位置/全额租金减免等。
US-06 AI Bot 回合
Bot 回合时，显示 Bot 思考动画（0.5-1.5 秒），决策后自动执行（买地/盖房/掷骰），日志显示 Bot 当前思考内容（"狐狸Bot 决定购买北京地块"）。
US-07 玩家资产面板
屏幕右侧或底部显示玩家资产面板：当前金币、地皮数量、建筑等级汇总、对手状态（资产估算）。实时更新。
US-08 竞拍机制
玩家放弃购买的地块，其他玩家可竞拍。竞拍时各 Bot 根据策略出价，玩家可选择退出。流拍则地块变为空置。
US-09 交易系统
玩家可向 Bot 发起地皮+金币交换提案。Bot 评估后接受/还价/拒绝。交易需双方确认后生效。
US-10 游戏结束与结算
所有对手破产后显示胜利画面（玩家胜）或资产结算排名（玩家败）。显示详细资产明细：地皮价值+现金+建筑价值。提供"再来一局"按钮。

10. Technical Approach

技术栈

  • 单文件 HTML — 所有逻辑内联，无需构建工具，部署极简
  • 纯原生 JS — 无框架依赖，保证加载速度
  • Canvas 2D — 地图渲染 + 动画
  • CSS Grid — UI 面板布局
  • localStorage — 保存游戏进度（可选）

地图数据结构

格子 = {
  type: 'land' | 'chance' | 'fate' | 'start' | 'station' | 'airport' | 'jail' | 'park',
  city: string,        // 城市名
  price: number,       // 购买价格
