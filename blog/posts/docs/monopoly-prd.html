大富翁 Online

版本 v0.1 · 状态：草稿 · 作者：Lob

一款基于中国城市地图的经典大富翁玩法网页游戏，支持玩家 vs AI Bot 单人模式，未来可扩展多人联机。

1. Executive Summary

经典大富翁玩法在中国有极强的情感基础（强手棋、大富翁游戏盘），但近年来缺乏有吸引力的线上版本。现有网页端产品普遍界面老旧、交互粗糙、AI Bot 无趣。

本产品定位为：一款精致、有策略深度、视觉风格现代化的中国城市大富翁网页游戏。以「玩家 vs AI Bot」为核心首发模式，重现经典地皮买卖、建造升级、命运卡、博弈对抗的核心乐趣。

差异化点：中国城市地图（省会+直辖市）+ 中国特色命运卡（政策/机遇/风险）+ 聪明有进攻性的 AI Bot + 现代暗色 UI。

2. Problem Statement

谁有这个问题？

20-40岁对中国经典大富翁有情怀记忆的用户，想要随时随地来一局，不需要下载 App，不需要队友。

现有方案的痛苦点：

  • 传统桌游：需要凑人、时间、道具，门槛高
  • Steam/App 大富翁游戏：需要下载安装，很多收费且品质参差
  • 网页版：界面老旧、交互反人类、AI Bot 弱智（永远买不到地/永远乱买）

证据：豆瓣/B站上经典大富翁相关内容持续有热度，但找不到一个能打的在线版本。

3. Target Users & Personas

核心用户

怀旧玩家
25-40岁，童年玩过强手棋/大富翁，现在想重温，但没有时间和人凑桌游。想要一个 AI Bot 能陪打的网页版，随时打开随时玩，30-60分钟一局。
策略游戏爱好者
18-35岁，喜欢回合制策略游戏（文明、英雄无敌），追求博弈深度。经典大富翁的"买地-盖房-收租"博弈链能否带来足够策略深度是他们的核心关注点。
休闲社交用户
18-30岁，和朋友远程玩游戏的场景。首发 AI 模式是替代方案，真正的目标是多人联机模式（Phase 2）。

4. Strategic Context

为什么现在？

  • HTML5 游戏技术成熟，单文件可承载复杂游戏逻辑
  • 大富翁核心玩法简单，但 AI Bot 设计有壁垒——好玩的 Bot 需要精心调参
  • Lob 站已有游戏矩阵（扑克/斗蛐蛐/德州扑克），大富翁是策略类补充
  • 中国城市 IP 有共鸣感，差异化强于"经典欧美地图"

Phase 规划

  • Phase 1（MVP）：玩家 vs 3个 AI Bot，单机运行，中国省会城市地图，完整大富翁核心玩法
  • Phase 2（联机）：WebSocket 中转，支持 2-4 人真实联机对战
  • Phase 3（社交）：好友系统、排行榜、录像回放

5. Solution Overview

地图设计

采用环形棋盘路线，共 40 格（与经典大富翁一致）。

  • 地皮格：28 格 — 中国省会/直辖市，每块地有价格、等级（空地→茅屋→房屋→楼房→摩天楼）、地价租金表
  • 机会格：5 格 — 抽取机会卡（获得收益/失去资产/特殊事件）
  • 命运格：5 格 — 中国特色命运（政策影响/市场波动/机会事件）
  • 起点格：1 格（1号） — 每次经过起点获得固定奖励（如 ¥2,000）
  • 公共设施格：3 格 — 火车站×2（7号北京/31号上海）、机场×1（32号成都）。火车站拥有后被路过收取¥200×骰子总点数；机场拥有后可传送任意城市（每局限1次）
  • 监狱/过路格：1 格（31号） — 路过正常支付过路费；连续掷三次双骰则被抓进监狱，禁足3回合
  • 免费停车格：1 格 — 无事发生

核心游戏循环

  1. 玩家回合开始 → 掷骰子 → 移动
  2. 落地判定：空地/已有地/机会/命运/特殊格
  3. 玩家决策：买地/竞拍/跳过
  4. AI Bot 行动（各自回合）
  5. 回合结束 → 下一玩家

胜利条件

所有玩家连续破产，或经过约定回合数（默认 20 回合）后，资产最高者胜出。

6. AI Bot 设计（核心壁垒）

AI Bot 是本产品的核心竞争力。好玩的大富翁需要 Bot 有"性格"和"策略"。

Bot 类型

🦅 鹰派Bot
激进买地、高频升级、优先攻击富裕玩家。有钱就盖房，抢占核心地块不惜负债。
🐢 龟派Bot
保守稳健、低买高卖、避免冲突。专注于积累免费地块，尽量少交易。
🦊 狐狸Bot
机会主义、擅长讨价还价。买地看对手而不是看价格，博弈谈判能力强。

Bot 决策模型

  • 每次落地：计算期望收益 vs 当前资金，决定买/竞拍/放弃
  • 每个回合结束：评估升级优先级（按地价/对手路过频率加权）
  • 对手接近时：优先升级对方必经之路的地块
  • 交易请求：根据自身资产/地块组合评估是否接受

注意：Bot 难度应可调。Easy Bot 有 30% 概率做出次优决策；Hard Bot 始终做最优决策（模拟蒙特卡洛搜索）。

7. Success Metrics

Phase 1 核心指标

  • 单局平均时长：30-60 分钟（玩家愿意花一局时间的证明）
  • AI Bot 胜率：玩家胜率 40-60%（Bot 既要有挑战性又不能太碾压）
  • 功能留存：进入游戏 → 完成一局的用户比例 ≥ 70%

未来指标

  • 人均游戏局数（复玩率）
  • 分享率（分享游戏截图到社交媒体）
  • 多人模式转化率（从 AI 模式引导到联机模式）

8. User Stories & Requirements

Epic：大富翁 MVP

作为一个怀旧玩家，我想要打开网页就能和 AI Bot 来一局大富翁，以便在碎片时间内重温经典游戏的乐趣。

US-01 地图渲染
地图完整渲染 40 格，含中国城市名称，环形排列，支持点击查看地块详情。地块颜色区分不同城市等级。
US-02 骰子与移动
点击骰子触发动画，两颗骰子点数显示，移动令牌平滑动画移动至目标格。可掷双骰（连续行动）或进监狱（掷出双骰三次触发）。
US-03 地皮买卖
落地空地时弹出购买确认框（价格/预期租金/已拥有者）。拥有地块后支持建造升级（茅屋→房屋→楼房→摩天楼），每次升级费用×1.5，租金×2。
US-04 租金结算
玩家落地对手地块时自动触发租金结算弹窗，动画显示金币从付款方转移至收款方。若余额不足则触发破产流程。
US-05 机会/命运卡
落地机会/命运格时，卡片从顶部滑入动画，内容随机。卡片类型：获得金币/失去金币/失去收益/免费盖房/移除建筑/交换位置/全额租金减免等。
US-06 AI Bot 回合
Bot 回合时，显示 Bot 思考动画（0.5-1.5 秒），决策后自动执行（买地/盖房/掷骰），日志显示 Bot 当前思考内容（"狐狸Bot 决定购买北京地块"）。
US-07 玩家资产面板
屏幕右侧或底部显示玩家资产面板：当前金币、地皮数量、建筑等级汇总、对手状态（资产估算）。实时更新。
US-08 竞拍机制
玩家放弃购买的地块，其他玩家可竞拍。竞拍时各 Bot 根据策略出价，玩家可选择退出。流拍则地块变为空置。
US-09 交易系统
玩家可向 Bot 发起地皮+金币交换提案。Bot 评估后接受/还价/拒绝。交易需双方确认后生效。
US-10 游戏结束与结算
所有对手破产后显示胜利画面（玩家胜）或资产结算排名（玩家败）。显示详细资产明细：地皮价值+现金+建筑价值。提供"再来一局"按钮。

9. Out of Scope

  • 多人联机模式（Phase 2）
  • 好友系统/排行榜（Phase 3）
  • 地图编辑器/自定义地图
  • 游戏录像回放
  • 中途退出保存/恢复
  • 移动端 App（仅支持桌面端浏览器）

10. Technical Approach

技术栈

  • 单文件 HTML — 所有逻辑内联，无需构建工具，部署极简
  • 纯原生 JS — 无框架依赖，保证加载速度
  • Canvas 2D — 地图渲染 + 动画
  • CSS Grid — UI 面板布局
  • localStorage — 保存游戏进度（可选）

地图数据结构

格子 = {
  type: 'land' | 'chance' | 'fate' | 'start' | 'station' | 'airport' | 'jail' | 'park',
  city: string,        // 城市名
  price: number,       // 购买价格
  rent: number[],      // [空地租金, 茅屋, 房屋, 楼房, 摩天楼]
  owner: null | playerId,
  level: 0-4,          // 0=空地, 1=茅屋, 2=房屋, 3=楼房, 4=摩天楼
  color: string,       // 地图颜色
}

性能目标

  • 首屏加载 < 500KB
  • 60fps 动画（骰子滚动/令牌移动）
  • Bot 决策延迟 ≤ 1.5 秒

11. Open Questions

  • Bot 策略调参：需要多轮内测确定"有趣"而非"变态"的 Bot 难度曲线
  • 移动端适配：Phase 1 是否需要支持触控操作？
  • 31号火车站（上海）与监狱格重叠，是否需要移除或调整？
  • Bot 是否需要"记牌"能力（追踪已出现卡牌）？

Decisions Made

  • 环形地图 40 格，与经典大富翁一致
  • Phase 1 为单机 AI Bot 模式，联机 Phase 2
  • 3 个 Bot 类型：鹰派/龟派/狐狸，各有性格
  • 单文件 HTML，Canvas + CSS Grid 技术栈
  • 胜利条件：全员破产或 20 回合后资产最高者胜
  • 颜色同色全占加成：集齐同色全部地块，该颜色租金+10% ✅
  • 机场每局限用1次 ✅
  • 地图修正（v0.2）：31号=监狱，32号=机场（成都）

Assumptions to Validate

  • 中国城市地图比抽象地图更有吸引力 [需用户验证]
  • AI Bot 足够好玩，复玩率可达 3+ 局 [需内测]
  • 30-60 分钟一局的时长玩家可接受 [需数据]
