大富翁 Online

版本 v0.2 · 状态：草稿 · 作者：Lob

中国城市地图 + AI Bot 单人模式网页游戏，重现经典买地/盖房/收租/博弈的核心乐趣。

1. 概述

经典大富翁在中国有极强情感基础（强手棋、大富翁游戏盘），但缺乏有吸引力的线上版本。现有产品界面老旧、AI Bot 无趣。本产品定位：一款精致、有策略深度、视觉现代化的中国城市大富翁网页游戏。

差异化点：中国省会城市地图 + 中国特色命运卡 + 聪明有性格的 AI Bot + 现代暗色 UI。

阶段规划：

  • Phase 1（MVP）：玩家 vs 3个 AI Bot，单机，中国省会城市地图，完整核心玩法
  • Phase 2：WebSocket 联机，2-4 人真实对战
  • Phase 3：好友系统、排行榜、录像回放

怀旧玩家

3. 游戏规则

3.1 核心循环

  1. 回合开始 → 掷骰子 → 移动
  2. 落地判定：空地 / 已有地 / 机会格 / 命运格 / 特殊格
  3. 决策：买地 / 竞拍 / 跳过 / 交易
  4. Bot 回合（3个 Bot 依次行动）
  5. 回合结束 → 下一玩家

3.2 胜利条件

  • 所有对手连续破产 → 胜利
  • 20回合后资产最高者胜
  • 若只剩 1 个玩家存活，提前结束，该玩家胜利
  • 平局：比较总资产（现金+地皮+建筑），精确到个位

3.3 地皮买卖与建造

购买：落地空地时弹窗确认（显示价格/预期租金/已拥有者）。玩家可选择购买或放弃。放弃则进入竞拍。

竞拍流程：玩家放弃购买时触发。

  • 显示"竞拍开始：{城市名}，起价 = 地价 × 60%"（向下取整至50的倍数）
  • 每次加价最低 ¥100，最高无限制
  • Bot 根据策略自动出价，玩家可随时退出
  • 所有人退出后，最高出价者获得地块；若全部退出，地块空置
  • 竞拍最多持续 10 轮，超时则流拍

建造升级：拥有地皮后可升级，共4级。

等级建造费租金说明
0 空地—地价×5%无建筑时收过路费
1 茅屋地价×30%地价×20%每块地可建1栋
2 房屋地价×50%地价×45%从茅屋升级
3 楼房地价×80%地价×80%从房屋升级
4 摩天楼地价×120%地价×150%最高级，从楼房升级

颜色同色加成：集齐同一颜色的所有地块后，该颜色所有地块租金 +10%。若有颜色加成状态（F-02/+50%）或城市升级（F-05/+15%），先计算加成再叠加。

3.4 特殊格

  • 起点（1号）：经过起点获得 ¥2,000。跨过0位时触发，开局在1号不算。
  • 火车站（7号，北京）：拥有后被路过收取 ¥200 × 当次骰子总点数。无建造升级。
  • 机场（32号，成都）：拥有后可传送到任意城市格（每局限用1次，不能传至火车站/机场/监狱）。传送不触发起点奖励。
  • 监狱（31号）：路过正常支付过路费。被抓进监狱：连续掷出三次双骰时触发 → 本次移动停止，直接进入监狱（跳到31号），禁足3回合。离开方式：付 ¥1,000 保释，或掷出双骰脱狱（否则跳过本回合）。
  • 免费停车（15号）：无事发生。

3.5 连续双骰规则

  • 掷出双骰：本回合获得额外行动（继续掷骰）
  • 连续3次双骰：立即进监狱（跳到31号），本次移动停止
  • 连续双骰计数器：在回合结束时重置（即"走到格子上后"不清零，本回合走完才清零）
  • Bot 同样受此规则约束

3.6 破产流程

玩家应付租金/费用 > 当前现金时，触发破产：

  1. 显示破产弹窗
  2. 所有现金 → 0
  3. 所有地皮+建筑 → 进入竞拍池（Bot 参与竞拍）
  4. 玩家出局，不再参与回合
  5. 若破产者是因付租金破产：租金仍需支付（竞拍后买家继承债权）

破产后的地皮通过竞拍重新分配，竞拍收益归系统（不分配给其他玩家）。

3.7 银行贷款

  • 最高负债额度：¥-5,000
  • 借款利率：10%（每回合结束时扣除）
  • 借款时机：任意时刻可借款（直至达到负债上限）
  • 还款时机：任意时刻可主动还款（无惩罚）
  • Bot 借款策略：鹰派允许负债至 ¥-8,000，龟派不允许负债，狐派允许负债至 ¥-3,000

4. AI Bot 设计

AI Bot 是核心竞争力。Bot 有"性格"和策略，分 Easy 和 Hard 两个模式。

难度设定：

  • Easy：鹰/龟 30% 概率做出次优决策；狐 40% 概率做出次优决策
  • Hard：始终做最优决策（模拟蒙特卡洛搜索），接受随机双骰结果（不会故意避免连续双骰）

Bot 类型与策略

🦅 鹰派 — 激进进攻型

  • 激进买地、高频升级、优先攻击富裕玩家。有钱就盖房，抢占核心地块不惜负债。
  • 买地阈值：资金 > 地价 × 60%
  • 升级阈值：资金 > 盖房费 × 80%
  • 攻击目标：优先升级对手必经之地
  • 交易态度：拒绝一切主动交易

🐢 龟派 — 保守稳健型

  • 保守稳健、低买高卖、避免冲突。专注于积累免费地块，尽量少交易。
  • 买地阈值：资金 > 地价 × 120%（Easy模式下30%概率提高到150%）
  • 升级阈值：资金 > 盖房费 × 150%
  • 攻击目标：优先升级自己已有地
  • 交易态度：等价交换可谈（±20%以内接受）

🦊 狐狸 — 机会主义型

  • 机会主义、擅长讨价还价。买地看对手而不是看价格。
  • 买地阈值：资金 > 地价 × 90%（Easy模式下40%概率放弃便宜地块）
  • 升级阈值：资金 > 盖房费 × 100%
  • 攻击目标：看对手资金，低买高卖
  • 交易态度：主动讨价还价，收到交易提案：净赚>¥500则接受，±¥500内则还价

Bot 决策模型（通用）

  • 每次落地：计算期望收益 vs 当前资金，决定买/竞拍/放弃
  • 每个回合结束：评估升级优先级（按地价/对手路过频率加权）
  • 对手接近时：优先升级对方必经之路的地块
  • 交易请求：根据自身资产/地块组合评估是否接受
  • 监狱内决策：若资金 > ¥5,000 则保释，否则尝试双骰脱狱

Bot 出场顺序

开局随机决定先手顺序（玩家 vs Bot1 vs Bot2 vs Bot3），每局重置。

通用规则

  • 所有卡片效果立即执行（除非另有说明）
  • 金币变化显示弹窗动画
  • 若无有效目标（如降级但已是最底层），卡片效果跳过

机会卡（C-01 ~ C-16）

6. 经济平衡

初始资源

项目数值
初始金币/玩家¥15,000
游戏开始金币总量¥60,000（4人）
起点奖励¥2,000（每圈注入 ¥8,000）
游戏总回合20回合

经济健康指标

通缩风险
每圈注入¥8,000，每次租金流出约¥300~¥1,500。注入量覆盖约5~26次基础租金，通缩风险低。
破产速度
持有S级地+摩天楼（¥15,000租金），对手每次路过损失¥15,000。Bot在3~5回合内积累足够资金触发破产。20回合足够决出胜负。
Bot强度
玩家初始¥15,000可购买2块A级地后剩余¥3,000~¥5,000，够支付1~2次租金。新手保护：前10回合若Bot连续买走3块S/A级地，剩余S/A价格临时-20%。玩家有喘息空间。
游戏时长
4玩家×20回合×平均2~4分钟/回合 ≈ 45分钟（符合30-60分钟目标）。

Phase 1 核心指标

  • 单局平均时长：30-60 分钟
  • 玩家胜率：40-60%（Bot 有挑战但不碾压）
  • 功能留存：进入游戏 → 完成一局 ≥ 70%

7. 用户故事

US-01 地图渲染
40格环形棋盘，含中国城市名称，支持点击查看地块详情，地块颜色区分等级。
US-02 骰子与移动
点击骰子触发动画，显示点数，移动令牌动画至目标格。处理双骰连续行动和三次双骰进监狱。
US-03 地皮买卖
落地空地弹出购买确认框（价格/预期租金/已有者）。拥有后可建造升级，每次升级费用×1.5，租金×2。
US-04 租金结算
落地对手地块时自动触发租金结算弹窗，动画显示金币转移。余额不足则触发破产流程。
US-05 机会/命运卡
落地机会/命运格时卡片顶部滑入动画，内容随机。所有效果精确执行（见第5节）。
US-06 AI Bot 回合
Bot 回合显示思考动画（0.5-1.5秒），决策后自动执行，日志显示当前思考内容。
US-07 资产面板
屏幕右侧/底部显示：当前金币、地皮数量、建筑等级、对手资产估算。实时更新。
US-08 竞拍机制
玩家放弃购买时触发竞拍，Bot 自动出价，玩家可退出，流拍则地块空置。（见3.3节竞拍流程）
US-09 交易系统
玩家向 Bot 发起地皮+金币交换提案。Bot 评估后接受/还价/拒绝，需双方确认生效。
US-10 游戏结束与结算
显示胜利/失败画面和资产明细，提供"再来一局"按钮。（见3.2节胜利条件）

8. 技术方案

技术栈：单文件 HTML + 纯原生 JS + DOM/CSS 绝对定位棋盘 + CSS Grid UI面板 + localStorage（可选）。

性能目标：文件 ≤ 200KB，首屏加载 < 1秒，动画 60fps，Bot 决策 ≤ 1.5秒。

地图数据结构：

格子 = {
  type: 'land' | 'chance' | 'fate' | 'start' | 'station' | 'airport' | 'jail' | 'park',
  city: string,       city: string,
  price: number,      rent: number[5],    owner: null | playerId,
  level: 0-4,         color: string,
}
玩家 = {
  cash: number,       assets: number,     position: 0-39,
  inJail: boolean,    jailTurns: number,   doubleCount: number,
  airportUses: 0-1,   generousMark: bool, holdings: string[],
}

9. 排除范围 / 决策 / 开放问题

Out of Scope：多人联机（Phase 2）、好友系统/排行榜（Phase 3）、地图编辑器、游戏录像回放、中途退出保存/恢复、移动端 App（仅桌面浏览器）。

Decisions Made：

  • 环形地图 40 格，与经典大富翁一致
  • Phase 1 为单机 AI Bot 模式，联机 Phase 2
  • 3 个 Bot 类型：鹰派/龟派/狐狸，各有性格
  • 颜色同色全占加成：集齐同色全部地块，该颜色租金+10%
  • 机场每局限用1次
  • 31号=监狱，32号=机场（成都），7号=火车站（北京）

Open Questions：

  • Bot 策略调参：需多轮内测确定"有趣"而非"变态"的 Bot 难度曲线
  • 移动端适配：Phase 1 是否支持触控操作？
  • Bot 是否需要"记牌"能力（追踪已出现卡牌）？
